# Apartado 7

Demostración sin red de una colección completa o interrumpida.

```powershell
.\.venv\Scripts\python.exe .\v07_resultados_parciales\main.py --max-paginas 1
.\.venv\Scripts\python.exe .\v07_resultados_parciales\main.py --max-paginas 2
```

También puedes ejecutar `python main.py` desde esta carpeta con el entorno virtual activo. Usa `--help` para consultar opciones. No requiere ejecutar otras versiones previamente; conserva los módulos comunes de la raíz.

Con --max-paginas 1 termina con código 2 intencionadamente: conserva la primera página y marca limite_paginas.
