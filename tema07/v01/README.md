# Cliente reutilizable para Teams

Consulta local con ClienteTeams y trazabilidad HTTP.

Desde la raíz del ZIP:

~~~powershell
python v01/main.py
~~~

También funciona desde esta carpeta con python main.py. Instala antes ../requirements.txt. Los módulos compartidos y .env están en la raíz del paquete; esta carpeta no depende de ningún otro ejemplo. Las salidas se guardan en v01/resultados/.

La ejecución sin argumentos es local y usa referencias ficticias. No necesita credenciales.
