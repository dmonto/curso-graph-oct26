# Mención de una persona

Prepara una mención de Laura Demo y simula su publicación.

Desde la raíz del ZIP:

~~~powershell
python v04/main.py
~~~

También funciona desde esta carpeta con python main.py. Instala antes ../requirements.txt. Los módulos compartidos y .env están en la raíz del paquete; esta carpeta no depende de ningún otro ejemplo. Las salidas se guardan en v04/resultados/.

La ejecución sin argumentos es local y usa referencias ficticias. No necesita credenciales.
