# Plantillas completas

Genera un mensaje HTML y una tarjeta Adaptive Card con 5 propuestas, 3 listas y 2 pendientes.

Desde la raíz del ZIP:

~~~powershell
python v03/main.py
~~~

También funciona desde esta carpeta con python main.py. Instala antes ../requirements.txt. Los módulos compartidos y .env están en la raíz del paquete; esta carpeta no depende de ningún otro ejemplo. Las salidas se guardan en v03/resultados/.

La ejecución sin argumentos es local y usa referencias ficticias. No necesita credenciales.
