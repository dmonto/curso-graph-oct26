# Miembros y roles

Consulta miembros y prepara payloads de alta, cambio de rol y baja sin aplicarlos.

Desde la raíz del ZIP:

~~~powershell
python v06/main.py
~~~

También funciona desde esta carpeta con python main.py. Instala antes ../requirements.txt. Los módulos compartidos y .env están en la raíz del paquete; esta carpeta no depende de ningún otro ejemplo. Las salidas se guardan en v06/resultados/.

La ejecución sin argumentos es local y usa referencias ficticias. No necesita credenciales.
