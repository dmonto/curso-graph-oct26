# Canales, publicación y respuestas

Lista canales y prepara crear-canal, publicar y responder. Admite todos los argumentos del programa teams_graph.

Desde la raíz del ZIP:

~~~powershell
python v02/main.py
~~~

También funciona desde esta carpeta con python main.py. Instala antes ../requirements.txt. Los módulos compartidos y .env están en la raíz del paquete; esta carpeta no depende de ningún otro ejemplo. Las salidas se guardan en v02/resultados/.

La ejecución sin argumentos es local y usa referencias ficticias. No necesita credenciales.
