# Resumen según estado

Genera las dos presentaciones para lectura completa con pendientes y para lectura parcial.

Desde la raíz del ZIP:

~~~powershell
python v10/main.py
~~~

También funciona desde esta carpeta con python main.py. Instala antes ../requirements.txt. Los módulos compartidos y .env están en la raíz del paquete; esta carpeta no depende de ningún otro ejemplo. Las salidas se guardan en v10/resultados/.

La ejecución sin argumentos es local y usa referencias ficticias. No necesita credenciales.
