# 2. Delegados y aplicación

Ejecutar desde la raíz: `python v02/main.py`.

Opciones: --modo delegada (por defecto, /me), --modo apponly (/users), --modo apponly --recurso me (diagnóstico negativo). Los informes se guardan en resultados/ de esta versión.

Usa solo módulos comunes de la raíz; no requiere ejecutar versiones anteriores.
